# Prompt Distiller — Agent Instructions

## Overview
This repository is the **Prompt Distiller**, a lightweight voice middleware tool that compresses messy human voice dictations (Russian, English, or mixed code-switching) into high-potency micro-prompts for reasoning LLMs.

## Architecture — Voice Dictation Pipeline

### Voice Dictation (`scripts/dictate_distill.py`)
- Triggered by `Shift+F4` keybind in Hyprland
- **Press 1 (Start):** Spawns `pw-record` → `~/.cache/prompt_distiller/recording.wav`, PID file → `~/.cache/prompt_distiller/recording.pid`
- **Press 2 (Stop & Process):** Kills `pw-record`, streams WAV to Wyoming Faster-Whisper on `127.0.0.1:10300`, distills raw transcript via `PromptDistiller`, injects result into focused window via `wtype` (or `wl-copy` + `evdev_paste.py`)
- Direct local Python imports for zero network overhead

## Core Modules
- `app/core/distiller.py` — `PromptDistiller` class with `distill_only()` method
- `app/core/models.py` — `LLMClient` + `MODEL_REGISTRY`; local-first (port 1235), LiteLLM cloud fallback
- `app/core/audio.py` — Whisper fallback transcription (used only if Wyoming is unavailable)
- `scripts/dictate_distill.py` — Main entrypoint executed by Hyprland keybind

## Local Model
- **Primary:** Qwen3.6-35B-A3B-MTP@IQ2_M on `http://127.0.0.1:1235/v1`
- **Provider config key:** `"local"` (maps to `custom_local` in the registry)

## What Does NOT Exist Here
- No FastAPI HTTP server
- No web UI
- No MCP server (removed in refactor to keep repo strictly focused on voice pipeline)
- No Telegram / Signal bots
- No Docker deployment

## Architecture & Benchmark Notes
- **Qwen2.5-Omni Evaluation (Aug 2026):** Tested `Qwen2.5-Omni-7B-Q4_K_M` with `mmproj-F32.gguf` on `llama-server`. While inference ran on Vulkan APU, `llama.cpp`'s audio projector embedding alignment remains experimental and produced hallucinated/degraded speech tokens. The 2-stage architecture (Wyoming Faster-Whisper ASR → 35B MoE text distiller) remains the proven, superior stack.
- **Future ASR Consideration:** If upgrading from Wyoming Whisper, test standalone fast ASR backends (e.g. `Qwen3-ASR-1.7B` or `SenseVoiceSmall`) that feed directly into the text LLM.
